1) Какую роль выполняет Unity в клиент-серверной схеме
Unity выполняет роль клиента: отправляет запросы, получает данные и изменяет модель в сцене. Сервер (готовый API https://cnc.kovalev.team/get/3) предоставляет данные станка и возвращает их в формате JSON, а Unity читает из них координаты и двигает по ним узлы модели станка

2) Какой HTTP-метод использует CncJsonController
CncJsonController использует метод GET — он только получает JSON и читает координаты станка, команды на сервер не отправляет (для отправки данных нужен был бы POST). Запрос делается через UnityWebRequest.Get(url) и SendWebRequest() внутри корутины Start, поэтому Unity не зависает, пока ждёт ответ. Запросы повторяются в цикле с паузой interval = 0.5 секунды

3) Как найти координату X внутри массива data
Массив data состоит из разделов. Сначала циклом foreach перебирают разделы и ищут тот, у которого название (section[0]) равно «Оси Канала 1». Затем в массиве строк этого раздела (section[1]) ищут строку, у которой название (row[0]) равно «Перемещение по оси X». Значение этой строки (row[1]), например «144,157 мм», и есть координата X. Так же находят Y и Z. Это делает метод GetCoordinate, а если координата не найдена, он выдаёт ошибку «Не найдена координата X»

4) Зачем удалять «мм» и заменять запятую точкой
Координаты в JSON приходят строками, например «144,157 мм», а для движения узла нужно число float. Метод float.Parse не понимает лишние буквы, поэтому «мм» удаляют. Запятую заменяют точкой, потому что float.Parse с CultureInfo.InvariantCulture читает дробную часть только через точку: «144,157 мм» → «144.157». Без этого будет ошибка FormatException, и узел не сдвинется. Потом число умножают на 0.001, чтобы перевести миллиметры в метры Unity
